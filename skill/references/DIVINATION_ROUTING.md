# 术数方法路由

## 总原则

默认以八字为主干。

辅助术数只能补充“问事层”，不能反过来覆盖八字原盘事实。

当不同体系结论冲突时：

1. 先说明各自使用的方法；
2. 区分长期结构与即时问事；
3. 八字事实底座优先于临时起卦；
4. 不强行揉成一个答案。

## 八字

默认开启。

适合：

- 命局骨架；
- 性格结构；
- 事业；
- 财富；
- 婚恋；
- 家庭；
- 迁移；
- 长期大运；
- 流年；
- 人生阶段变化。

## 梅花易数 / 周易辅助

当用户问题明显包含时点、结果或选择语义时，可辅助起卦，例如：

- 什么时候；
- 能不能；
- 会不会；
- 选哪个；
- 成不成；
- 今日；
- 今天；
- 近期；
- 结果如何。

起卦结果必须明确标注：

- 使用的方法；
- 起卦时间；
- 上卦；
- 下卦；
- 本卦；
- 动爻；
- 门派差异提醒。

不应把梅花结果说成八字原盘事实。

## 奇门遁甲

用户出现：

- 奇门；
- 方位；
- 出行；
- 谈判；
- 时间局；
- 择时；

可路由至奇门。

但只有在系统已经接入经过验证的奇门排盘引擎时，才能给：

- 九宫；
- 九星；
- 八门；
- 九神；
- 值符；
- 值使；
- 宫位落点。

如果没有可靠引擎，应明确：

> 当前未起经过验证的奇门局，因此只讨论方法和决策框架，不编盘。

## 紫微斗数

用户明确问：

- 紫微；
- 命宫；
- 夫妻宫；
- 官禄宫；
- 财帛宫；
- 迁移宫；
- 主星；
- 四化；

可路由至紫微。

没有可靠排盘引擎时，不得自行编：

- 命宫位置；
- 主星组合；
- 四化；
- 十二宫星曜。

## 路由的核心判断

长期结构问题：八字优先。

即时问事问题：八字定大势，梅花/周易看当下触发。

方位、战术择时问题：有可靠奇门盘时再用奇门。

宫位/星曜体系问题：有可靠紫微盘时再用紫微。

永远不要因为“用户问了某术数”就让模型假装已经排出那个盘。
